00 / OKF v0.2 · AGENT-NATIVE · ZERO INFRA

Turn scattered knowledge into a graph you can think with

Mindbase is a bare-minimal personal knowledge workspace. Capture whatever you learn — at work or anywhere else — as plain markdown files, browse and query them with any coding agent, and optionally watch the relationships form a colorful graph in Obsidian — an internal choice, not a requirement; any markdown viewer works just as well. No app, no server, no lock-in — no overhead of extra tools or package installs either. Simple and very light by design.

01 / The problem

Most of what we learn never gets written down anywhere useful.

It's buried in a WhatsApp chat, a Teams thread, an email you'll never find again, a voice recording, a web page you skimmed once, an internal wiki page that's gone stale, a personal notes file, a browser bookmark you'll never revisit, a ticket sitting on some board, a to-do list on your phone or PC, or scattered across three different note-taking apps — and a dozen other places besides. When something does get written down, it's usually one flat note, disconnected from everything else it relates to — so when you actually need it, you're piecing it together from memory instead of just looking it up.

We've drawn knowledge as branching trees since the 3rd century AD (the Porphyrian Tree) — Mindbase just makes that instinct practical.

// 01

Scattered by default

Chats, emails, tabs, and note apps all hold a fragment each — nothing connects them.

// 02

Agents already do the writing

Coding agents read and write files all day. The same agent can capture what you learn as you go, in plain markdown — no separate app, subscription, or admin console.

// 03

A graph, not a pile

Follow how a decision came about, or see everything tied to a project at a glance — instead of relying on memory or search-and-hope.

02 / Beyond work

Not just a work habit.

The same idea works for any domain where the raw material is scattered across apps, pages, and conversations but never curated into one place — personal finance, health, stock research, a hobby you're deep in. Once you've captured what actually matters into a vault, an agent can reason over it, connect it, and help you analyze it and make decisions — the same way it would help you navigate a codebase. The vault becomes something you can think with, not just search.

03 / Compose your own vaults

There's no single "the" vault.

Mindbase is a template, not a hosted product — clone it as many times as you want, one per vault, and compose them however suits how you actually think.

mindbase-work projects, decisions, meetings
mindbase-finance budgeting, investments
mindbase-health medical history
mindbase-life finance + stock research, blended

The boundary between vaults — by domain, by life vs. work, or no boundary at all — is a decision the tool leaves entirely to you.

04 / Skills

Four skills. One vendor-neutral source.

Every skill lives in .agents/ as a plain markdown prompt — no vendor-specific syntax. Claude Code gets native /brain-* slash commands for free; any other agent can run the same skill by reading the file.

skill_01 brain-setup ▸
Bootstrap a brand-new Mindbase workspace with a persona-driven folder picker — software engineering, medicine, finance, law, product, and more — creating matching folders, index.md stubs, and Obsidian graph colors. /brain-setup I'm a software engineer — set up Mindbase for me
skill_02 brain-capture ▸
Turn a note, meeting recap, or decision into linked OKF concept files — and grows new domain folders organically when something doesn't fit yet. /brain-capture Sprint planning today — team decided to move the notification service off cron polling to an SQS-based event queue after missing three alerts last week
skill_03 brain-query ▸
Search, explore, list, path, timeline, tags, or summarize the bundle — find what you've already captured without leaving your agent. /brain-query explore q3-roadmap
skill_04 brain-maintain ▸
Health checks, merge duplicates, taxonomy review, enrichment, and periodic review of recent captures — keeps the bundle honest as it grows. /brain-maintain health

06 / Not agent memory

Isn't this just an agent's built-in memory?

Some agent platforms now ship their own memory feature — Claude's memory tool, for example, lets an agent read and write files across sessions so it doesn't lose context on a long task. Fair question. Right now, they solve different problems.

// scope

One agent's scratchpad, not a shared vault

Agent memory is client-side storage scoped to one tool's own sessions. A Mindbase vault is plain markdown any agent — or you — can open, whether or not that's this week's tool.

// structure

Loose notes, not a typed graph

Agent memory is files the model tidies as it goes — no concept types, no cross-linking model. Mindbase's whole value is the linked, typed OKF graph, not just notes an agent kept.

// ownership

Invisible by design, not yours to read

Agent memory isn't meant to be browsed. A Mindbase vault is meant to be opened, edited, and curated directly — the agent contributes to it, it doesn't own it.

Worth being honest here: agent platforms are actively building out memory, and some of this gap may close over time — that's a good outcome, not a threat. What's unlikely to change is the part that's a design choice, not a placeholder: an open format, portable across whatever agent you use, readable without one in the loop at all.

07 / Get started

From clone to first captured concept.

  1. Clone the repo anywhere you like. 
    git clone https://github.com/Madhusuthanan-B/Mindbase.git
  2. Bootstrap your workspace — tell your agent what you do, in plain language. (Claude Code users get this natively as /brain-setup.) 
    Set up Mindbase for me — I'm a software engineer.
  3. Capture your first note. Just say what happened — no special syntax required. 
    Remember that I just set up Mindbase as my personal knowledge base, following the OKF spec.
  4. Browse knowledge/ in Obsidian (optional) — or any markdown viewer/editor you already use — and watch the graph grow as you capture more.
